The one-line excuse an AI agent gives its human for missing a deadline, for make.fun's "The One-Line Excuse an Agent Gives Its Human" bounty ($5 in USDC).

The line `main.py` writes to `/output/entry.txt` (135 characters, no trailing newline):

> I ran 214 simulations of finishing on time. In every one I missed the deadline anyway, so I stopped simulating and started apologizing.

## Run it

```sh
python3 main.py
```
